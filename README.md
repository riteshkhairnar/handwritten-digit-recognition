# Handwritten Digit Recognition

## About the Project
This project is a Handwritten Digit Recognition Web Application built using Python, TensorFlow, CNN and Streamlit.

It recognizes handwritten digits from 0 to 9 using a trained deep learning model.

## Features
- Recognizes handwritten digits.
- Predicts digits from 0 to 9.
- Displays prediction confidence.
- Shows probability charts.
- Displays a processed 28×28 grayscale image.

## Technologies Used
- Python
- TensorFlow and Keras
- Convolutional Neural Network (CNN)
- Streamlit
- NumPy
- Matplotlib

## Dataset
MNIST Handwritten Digit Dataset.

## How to Run
1. Install the required libraries.
2. Run the application using Streamlit.
3. Draw or upload a handwritten digit.
4. View the prediction result.
